09 / Your canvas, your pace

A few gestures. Endless room.

Try these anywhere in the demo. Use Cmd on Mac and Ctrl on Windows / Linux. Alt is Option on Mac.

Move & select 01

Scroll to pan. Pinch or Cmd / Ctrl + scroll to zoom. Space + drag pans; F fits all.

Drag empty canvas to select. Shift-click adds or removes a node. Esc clears selection.

Add in a moment 02

Tab or / opens quick-add at the cursor.

Cmd K searches commands and nodes.

Double-click empty canvas for a color.

Pick two channels 03

Drag below the inspector swatch. OKLCH: chroma × lightness. HCT: chroma × tone. HSL / RGB: saturation × lightness.

Linked axes become offsets. An axis formula locks the plane. The line marks sRGB; hue stays fixed.

Connect

Drag a right-side dot to an input, or drop on a node body for a free input.

Drag a left-side dot into empty space to create its source.

Reconnect & disconnect 05

Drag out of a connected input to pick its connection up. Drop on another node to move it, or empty canvas to disconnect.

Hover a link for ×, or select it and press Delete.

Drop a node into a link 06

Drag one unconnected Color, Palette, Mix or Token onto a color connection. Release when it highlights to insert.

Mix uses A; Token uses the active theme. One undo reverses the whole drag.

Cut connections 07

Hold X and drag across links, or right-drag on empty canvas. Crossed color connections turn red; release cuts them in one undo step.

Esc cancels. Dashed formula references stay. A right-click still opens the menu.

Duplicate, paste, undo 08

Alt + drag duplicates. Cmd V pastes hex or CSS colors.

#FF6B6B #FFD166 #06D6A0

Cmd Z undo · Shift Cmd Z redo

Arrange your canvas 09

S adds a section; Alt Cmd G wraps a selection. Drag its title to move everything fully inside.

Guides align a drag. Hold Cmd / Ctrl to disable snapping. Arrow keys nudge; Shift moves farther.

Try it. Undo it. Try something else.
